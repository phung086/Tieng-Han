# Haneul interface

Haneul is an Operate surface: Vietnamese learners study Korean and manage source-backed learning work. Preserve the purple identity, Be Vietnam Pro, Noto Sans KR, supplied notebook fonts and navigation. This update reorganizes workflow and shared hierarchy; it does not replace the architecture or learning thresholds.

Use white working surfaces on a quiet neutral background, purple for current steps and primary actions, green for confirmed completion, amber for inactivity, red for a reported error. Status always has text and an icon. Shared values live in src/app/workflow-experience.css. Avoid decorative gradients, oversized cards and repeated eyebrow labels in working screens.

Each asynchronous workflow has an evidence-based rail: confirmed stages, latest activity time, a precise waiting point, recovery guidance and a detailed log. HTTP acceptance is delivery evidence, not model execution. Never guess provider credits or internal inference status from inactivity. Keep logs free of credentials and source text. Do not manufacture compilation percentages.

Choice questions submit on selection. Correct responses advance after 3.5 seconds, with a persistent toggle and per-question pause. Wrong responses wait for explicit continuation. Stop timers in hidden tabs and on unmount; retain final summaries. Motion lasts 180 ms and respects reduced motion. Input answers respect Korean IME composition.

Desktop places source editing and notebook preview alongside each other; mobile exposes one at a time, with the processing rail outside the panes. Received worksheet results open the preview automatically; only scroll to the file once it is ready. File preparation errors preserve editable content.

Controls have visible keyboard focus and at least 44 px primary touch targets. Workflow stages stack on narrow screens; timestamps use tabular figures. Verify real desktop/mobile states in a bounded pass, then confirm the defects fixed.
