# Content model

Mỗi lesson phải được dựng từ source map và đi qua flow: objectives → vocabulary → grammar → controlled practice → speaking → listening → reading → writing → pronunciation → culture → review → mastery-test.

## Question metadata

```json
{"sourceBook":"","sourceChapter":"","sourcePage":0,"sourceSection":"","skill":"","grammarPoints":[],"vocabularyIds":[],"difficulty":1,"prerequisites":[],"answer":null,"explanation":"","sourceEvidence":[]}
```

Không có `sourceEvidence` thì không publish. Nội dung bổ trợ chỉ được truy xuất từ phần người học đã mở khóa.
