# Notebook fonts

Unmodified fonts distributed under the bundled SIL Open Font License files.
Downloaded 2026-10-06 from the Google Fonts repository:

- https://github.com/google/fonts/tree/main/ofl/badscript
- https://github.com/google/fonts/tree/main/ofl/himelody

Vietnamese uses Bad Script; Hangul uses Hi Melody (compressed to WOFF2,
with original outlines and family name preserved). Fonts are self-hosted,
so notebook rendering/export does not depend on a remote font service.

Bad Script includes every precomposed Vietnamese letter/mark in U+1EA0–U+1EF9.
Vietnamese rendering uses per-letter slant, height and baseline variation instead
of the previous polished Dancing Script. Accents remain attached to their NFC
letter. This approximates the reference's thin, irregular pen writing; it is not
an exact reproduction of the writer's handwriting.
